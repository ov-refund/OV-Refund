# Website

Deze map is de website van OV Refund: <https://ov-refund.github.io/OV-Refund/>. GitHub Pages publiceert hem via `.github/workflows/pages.yml` bij elke wijziging in `site/` op `main`. De app zelf staat in de rest van deze repository, de downloads bij [Releases](https://github.com/ov-refund/OV-Refund/releases/latest).
